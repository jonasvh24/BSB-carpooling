# Compliance register

> **As found on 2026-09-30, before any fix (Phase B).** Phase C rewrites the Status, Evidence and Action columns as gaps are closed.

Status: working document for the pilot owner and their lawyer. It records what the code does and where; it is not legal advice and the author is not a lawyer. Legal judgement calls are in `LAWYER_QUESTIONS.md`.

- **Status**: `OK` (requirement met, evidence given) · `GAP-CODE` (a code change closes it) · `GAP-DOC` (a document must be written or corrected) · `ACTION-ARNO` (a non-code action for the pilot owner) · `LAWYER` (needs a legal decision; the code can follow either answer).
- **Legal source + confidence**: `[HIGH]` the source exists and says this; `[MED]` the law or guidance exists but the exact article or reading was not verified; `[LOW]` the author's understanding only.
- **Evidence**: `` `path:line` ⟨needle⟩ `` (checked by `node scripts/legal-refs.mjs`), a test name, or a command output.
